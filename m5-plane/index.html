Set up the M5Stack (once)

  1. Install the Arduino IDE. In Boards Manager add M5Stack (or esp32 by Espressif).
  2. In Library Manager install M5Unified and PubSubClient.
  3. Open m5_imu_stream.ino and fill in your Wi‑Fi name, password and a device id.
  4. Pick your board (e.g. M5Core2, M5StickCPlus, M5CoreS3) and its USB port, then Upload. After that the USB cable is only for power.
  5. The screen shows Streaming once it reaches the broker. This page then turns green: Live.

The device publishes to the public broker broker.hivemq.com on topic ifm-met/iiot/m5/anand-m5/imu. Any browser anywhere can watch it. Use a different id with ?id=yourname.

Zero (or button A on the device) sets the current pose as level flight. Heading drifts slowly because the IMU has no compass, so press Zero again when it does.

Use a phone hotspot or a normal WPA2 network. Eduroam's enterprise login won't work. Demo plays simulated motion if the device isn't online.
